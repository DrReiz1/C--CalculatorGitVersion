# C--CalculatorGitVersion
Calculadora em console desenvolvida em C# para consolidar fundamentos da linguagem, lógica de programação (laços de repetição, condicionais) e operadores aritméticos (como Math.Pow). O projeto foi idealizado estritamente para fins de aprendizado e para praticar o fluxo de versionamento de código e boas práticas de commit com o Git.
