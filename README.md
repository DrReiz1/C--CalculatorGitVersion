# Console Calculator (C# & Git Practice)

Uma calculadora simples executada no terminal, desenvolvida em **C#** com o objetivo de consolidar os fundamentos da linguagem, aplicar lógica de programação e praticar o fluxo de versionamento de código utilizando o **Git**.

## 🎯 Objetivos do Projeto
Este projeto foi desenvolvido estritamente para fins de estudo e prática pessoal, focando em:
*   **Fundamentos de C#:** Manipulação de variáveis, entrada e saída de dados via console (`Console.ReadLine`, `Console.WriteLine`), conversão de tipos de dados e controle de fluxo.
*   **Lógica de Programação:** Implementação de estruturas condicionais (`if/else`), estruturas de escolha (`switch/case`) para direcionar operações, e laços de repetição (`while`) para manter o programa rodando continuamente.
*   **Versionamento com Git:** Prática de boas práticas de commits, gerenciamento de histórico e organização do repositório no GitHub.

## 🧮 Funcionalidades
A calculadora permite realizar as seguintes operações consecutivas sem a necessidade de reiniciar o sistema:
1.  **Adição** (`+`)
2.  **Subtração** (`-`)
3.  **Multiplicação** (`*`)
4.  **Divisão** (`/`) — *Com validação para impedir divisão por zero.*
5.  **Resto da Divisão** (`%`) — *Com validação de segurança.*
6.  **Potenciação** (`Math.Pow`) — *Utilizando casting para manipulação de tipos inteiros.*
0.  **Sair** — *Encerramento seguro do programa.*

## 🛠️ Tecnologias Utilizadas
*   **Linguagem:** C# (.NET)
*   **Ambiente:** Console Application
*   **Controle de Versão:** Git / GitHub
